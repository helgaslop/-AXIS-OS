Почати за 4 кроки

1
Завантаж і встанови

Завантаж .exe інсталятор, запусти — AXIS OS встановиться автоматично.

2
Введи API ключі

Вкажи ключі потрібних сервісів. Зберігаються у Windows Credential Manager.

Клікни «Запустити сферу» — плаваюча куля. Скажи «axis» і дай команду.

Налаштуй під себе

Створюй власні команди, підключай Spotify і Telegram.

Питання про підписку

Як ввести ліцензійний ключ?▼

Запусти AXIS OS → меню зліва → «Ліцензія» → вставте ключ у поле і натисни «Активувати». Все, більше нічого не потрібно.

Ключ прив'язаний до ПК?▼

Місячний і Річний — до одного пристрою. Lifetime — необмежена кількість пристроїв.

Що буде після закінчення пробного?▼

AI Чат обмежується до 20 повідомлень/день, голос до 30 команд/день. AI Агенти і генерація зображень вимикаються. Решта функцій працює.

Чи є повернення коштів?▼

Так, протягом 3 днів після покупки якщо є технічні проблеми які ми не змогли вирішити.

Чи автоматично продовжується підписка?▼

Ні. Оплата ручна через Telegram — ніяких автосписань. Ти сам вирішуєш коли продовжувати.

FAQ

Часті питання

Чи потрібен інтернет?▼

Базовий голос і команди — офлайн. AI чат потребує інтернет і API ключі.

Як зберігаються API ключі?▼

Windows Credential Manager — зашифровано вашим паролем. Ніколи не передаємо нам.

Які системні вимоги?▼

Windows 10/11, Python 3.10+, RAM 4GB+. GPU не потрібен.

Платити за ChatGPT окремо?▼

Так, API ключі — безпосередньо провайдерам. Підтримується безкоштовний Ollama.

Відкритий вихідний код?▼

Так, GitHub. Можна переглядати і запускати самостійно.

Як отримати підтримку?▼

GitHub Issues, Telegram @Helgaslopp або Email axis.os.assistant@gmail.com. Lifetime — VIP підтримка.
