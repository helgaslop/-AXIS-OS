⬡ AXIS OS — Довідка

Все що потрібно знати для роботи з голосовим асистентом та панеллю керування

🚀 Швидкий старт ▼
1
Встанови API ключіПерейди в API Ключі → введи свій OpenAI або інший ключ → Зберегти
2
Запусти сферуКлікни ⬡ Запустити сферу на головній або через трей. Сфера слухає команди голосом.
3
Скажи командуПриклади: «відкрий chrome», «яка погода», «включи музику»
4
Створи свою командуКоманди → + Нова команда → заповни форму
💡 Порада: Натисни Ctrl+K будь-де в панелі — відкриється швидкий пошук команд
📋 Як створювати команди ▼
1
Тригерна фразаСлово або фраза, яку говориш сфері. Натисни 🎤 щоб продиктувати голосом.
2
Тип команди Shell — запустити програму або .exe
URL — відкрити сайт у браузері
Python — виконати Python код
Система — внутрішня дія AXIS
3
Дія (тіло команди)Що виконати: назва програми, URL, або код. Приклади:
chrome · https://youtube.com · notepad.exe
4
Гаряча клавіша (необов'язково)Клікни поле → натисни потрібну комбінацію. Команда виконається за цим хоткеєм.
5
ДодатковоАльтернативні фрази (через кому), іконка, опис. Перемикач «🎤 Сфера слухає» — чи реагувати голосом.
💡 Швидко: Натисни «✨ Шаблони» — готові команди для Chrome, YouTube, системи тощо
🎙️ Голосова сфера ▼
1
ЗапускГоловна → «⬡ Запустити сферу» або через іконку в треї
2
Wake wordЗа замовчуванням скажи «axis» або «ейксіс» — сфера почне слухати команду
3
Режими сфери Normal — одна команда за раз
Live — постійне слухання без wake word
Dialog — режим розмови з AI
4
ЖестиКлік по сфері — активувати · Правий клік — меню · Подвійний клік — сховати/показати

❓ Часті питання ▼
Сфера не реагує на голос
Перевір: 1) Мікрофон обраний у Налаштуваннях → STT 2) Рівень чутливості 3) Сфера запущена (іконка в треї)
Команда виконується але нічого не відбувається
Перевір тіло команди — натисни ▶ на карточці команди для тесту. Деталі в Логах.
AI не відповідає
Перевір API ключ: API Ключі → 🔍 Перевірити ключі. Переконайся що є баланс на рахунку.
Spotify не підключається
API Ключі → введи Client ID і Client Secret → натисни «Підключити Spotify» → авторизуйся у браузері
Як видалити команду
Команди → знайди команду → натисни 🗑 або відкрий редагування і видали
Як зробити резервну копію
Налаштування → Резервне копіювання → Зробити бекап. Файл збережеться на Робочий стіл.
